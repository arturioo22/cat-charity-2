# QRKot - Благотворительный фонд поддержки котиков (Версия 2.0)

QRKot - это сервис для благотворительного фонда, который собирает пожертвования на поддержку кошачьей популяции. Приложение позволяет создавать целевые проекты (сборы на конкретные нужды) и автоматически распределять поступающие пожертвования между открытыми проектами.Версия 2.0 добавляет полноценную аутентификацию пользователей и разграничение прав доступа.

## Возможности проекта

- Создание целевых проектов с указанием названия, описания и требуемой суммы
- Приём пожертвований с возможностью добавления комментария
- Автоматическое инвестирование пожертвований в открытые проекты (по принципу FIFO - первым пришёл, первым обслужен)
- Автоматическое закрытие проектов при достижении требуемой суммы
- Автоматическое распределение остатка пожертвования между следующими проектами
- Инвестирование нераспределённых пожертвований в новые проекты при их создании
- Полный CRUD для управления проектами (создание, чтение, обновление, удаление)
- Просмотр всех пожертвований с детальной информацией

## Аутентификация и авторизация

- Регистрация и аутентификация пользователей с использованием JWT токенов
- Три уровня доступа: анонимный пользователь, зарегистрированный пользователь, суперпользователь
- Персонализированные пожертвования (сохраняется информация о пользователе)
- Просмотр пользователем только своих пожертвований

## Технологии

- Python 3.12
- FastAPI 0.104+
- FastAPI Users 12.1+ (аутентификация)
- SQLAlchemy 2.0+ (асинхронный)
- Pydantic 2.5+ для валидации данных
- Alembic для миграций базы данных
- SQLite + aiosqlite (асинхронный драйвер)
- JWT для токенов аутентификации
- Passlib + Bcrypt для хеширования паролей
- Uvicorn для запуска приложения

## Установка и запуск

1. Клонировать репозиторий:
```bash
git clone <url-репозитория>
cd cat-charity-1
```
2. Создать и активировать виртуальное окружение:
```bash
python -m venv venv
venv\Scripts\activate
```
3. Установить зависимости:
```bash
pip install -r requirements.txt
```
4. Настроить переменные окружения (опционально):
Создайте файл .env в корне проекта:
APP_TITLE="Благотворительный фонд поддержки котиков QRKot"
APP_DESCRIPTION="Сервис для поддержки котиков"
DATABASE_URL="sqlite+aiosqlite:///./fastapi.db"

5. Применить миграции базы данных:
alembic upgrade head

6. Запустить приложение:
uvicorn app.main:app --reload

Приложение будет доступно по адресу http://127.0.0.1:8000
